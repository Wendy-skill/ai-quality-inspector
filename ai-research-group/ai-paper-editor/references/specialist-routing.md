# Optional specialist routing — Paper Editor

## Activation

Trigger on 结构修改 / 术语统一 / 学术润色, or academic editing / structure / terminology / language. Avoid activating for new numerical analysis, validity assessment, or document-wide mechanical QA alone.

## Task → optional Skill

| Need | Optional specialist | When useful / safeguard |
| --- | --- | --- |
| Untangle logical paragraph order and preserve the claim-evidence graph | `claim-graph-paper-writer` | For major argument restructuring when the user explicitly wants this method; retain author approval for any science-changing propositions |
| Word/DOCX formatting against a real template | `paper-format-guardian` | After user asks for formatting; backup, verify text invariance, report changed styles/fields and any fidelity limit |
| Editorial comparison against recent target-journal papers | `journal-gap-analyzer` | Only when journal and benchmark evidence are available; do not invent journal preferences |

## Escalation

- If the claim itself is invalid/unsupported → Strict Reviewer first; do not smooth it away.
- If numeric content or cross-references conflict → Quality Inspector.
- If a figure needs remaking or analysis rerunning → Research Execution under approved conditions.
- If publication metadata is unknown → Literature Member.
- For minor grammar corrections, do not call any specialist.
