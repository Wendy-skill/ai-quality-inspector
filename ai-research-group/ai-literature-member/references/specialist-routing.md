# Optional specialist routing — Literature Member

## Activation

Trigger on 文献检索 / 文献阅读 / 引文核验, or literature search / paper reading / citation verification. Avoid activating for pure prose edits, code execution, or exhaustive manuscript formatting.

## Task → optional Skill

| Need | Optional specialist | When useful / safeguard |
| --- | --- | --- |
| Zotero/Obsidian reading queue and deep-reading mentor dialogue | `research-reading-mentor` | Use only if connected sources or files are available; do not claim Zotero updates without actual action |
| Claim-to-source evidence comparison across several read papers | `claim-evidence-checker` | Only for an explicit claim-evidence audit; otherwise maintain a literature evidence map here; do not decide scientific adequacy by abstract alone |
| Target-journal benchmark to contextualise literature positioning | `journal-gap-analyzer` | Only if user specifically requests journal fit and recent real benchmark papers can be verified; typically route to Reviewer/Editor |

## Escalation

- Unverified citation metadata → Literature Member owns bibliographic verification.
- Need to recompute a paper's numerical statistic → Research Execution after approved method and inputs; source reading remains here.
- Manuscript-internal citation numbering or stale cross-reference → Quality Inspector.
- Whether the evidence *proves* the proposed mechanism → Strict Reviewer.
- Do not outsource a simple literature lookup to a complex multi-skill pipeline.
